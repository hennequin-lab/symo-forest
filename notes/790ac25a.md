# Factor coordinates are width-dependent; Wedderburn blocks are width-independent

An invariant operator $bold(S) in cal(C)(W, W)$ on $W = V^(⊗k) ⊗ F$ ($dim V = n, dim F = f$) admits two distinct representations in `symo`:

1. **The factor list $bold(c) = (bold(C)_1, dots, bold(C)_d)$ (`Orbit.Second_order.factors`):** the coefficients of $bold(S)$ in the compiled [[a0bb3d95|diagram basis]] ${bold(T)_1, dots, bold(T)_d}$:
   ```typst
   bold(S) = sum_(k=1)^d bold(T)_k ⊗ bold(C)_k, quad bold(C)_k in RR^(f times f).
   ```
2. **The Wedderburn blocks $(bold(B)_lambda)_lambda$ (`Blocks.block_matrices`):** the operator's action on the multiplicity-and-free spaces $cal(M)_lambda ⊗ F$ in an orthonormal basis of [[46af9ff5|the isotypic decomposition]]:
   ```typst
   bold(S) = ⊕_lambda (bold(I)_(cal(S)_lambda) ⊗ bold(B)_lambda), quad bold(B)_lambda in RR^((m_lambda f) times (m_lambda f)).
   ```
Confusing these two objects — for instance, attempting to apply a nonlinear matrix function $f$ directly to the factor matrices $bold(C)_k$, or assuming that the same numeric factor list $bold(c)$ represents "the same operator" at two different widths $n != n'$ — is a fundamental algebraic error. **The blocks $(bold(B)_lambda)_lambda$ are the operator's matrix representation under an algebra isomorphism; the factors $bold(c)$ are coordinates in a non-orthogonal diagram basis ${bold(T)_k}$ that depends on $n$.**

## Explicit comparison at $k = 1$

For $k = 1$, there are $d = B_2 = 2$ diagram terms on $V = RR^n$ and two isotypic kinds $lambda in {emptyset, [1]}$ with projectors $bold(Pi) = frac(1, n) bold(J)_n$ and $bold(Pi)_perp = bold(I)_n - bold(Pi)$ ([[d47131ad|the Π/Π⊥ projector basis]]).

- **In the unnormalized $delta / 1$ basis** ${bold(I)_n, bold(J)_n}$, writing $bold(S) = bold(I)_n ⊗ bold(F) + bold(J)_n ⊗ bold(G) = bold(Pi) ⊗ bold(B)_emptyset + bold(Pi)_perp ⊗ bold(B)_([1])$ gives the linear dictionary
  ```typst
  bold(B)_emptyset = bold(F) + n bold(G), quad quad
  bold(B)_([1]) = bold(F).
  ```
  Here the conversion from coordinates $(bold(F), bold(G))$ to blocks $(bold(B)_emptyset, bold(B)_([1]))$ is neither diagonal (since $bold(B)_emptyset$ mixes $bold(F)$ and $bold(G)$) nor width-independent (since $bold(G)$ is multiplied by $n$).
- **In `symo`'s normalized diagram basis** (`Term.normalization`), the two basis tensors are $bold(T)_([1]) = bold(I)_n$ ($alpha = 1$, zero untied axes) and $bold(T)_emptyset = frac(1, n) bold(J)_n = bold(Pi)$ ($alpha = (n^2)^(-1/2) = frac(1, n)$, two untied axes), with coordinates $bold(C)_([1]) = bold(F)$ and $bold(C)_emptyset = n bold(G)$. Substituting $bold(I)_n = bold(Pi) + bold(Pi)_perp$ into $bold(S) = bold(Pi) ⊗ bold(C)_emptyset + bold(I)_n ⊗ bold(C)_([1])$ gives
  ```typst
  bold(B)_emptyset = bold(C)_emptyset + bold(C)_([1]), quad quad
  bold(B)_([1]) = bold(C)_([1]).
  ```
Notice that for $k = 1$, the normalization factor $alpha_emptyset = frac(1, n)$ happens to absorb the explicit factor of $n$ in $bold(B)_emptyset = bold(F) + n bold(G)$, making the $k = 1$ coordinate-to-block map $bold(Phi)_n$ independent of $n$. Even so, $bold(Phi)_n$ is triangular rather than diagonal: $f(bold(B)_emptyset) = f(bold(C)_emptyset + bold(C)_([1])) != f(bold(C)_emptyset) + f(bold(C)_([1]))$ for any nonlinear function $f$ (such as $x mapsto x^(-1)$ or $x mapsto x^(1/2)$).

## Genuine width-dependence of factor coordinates at $k = 2$

When $k = 2$ (two tied permuted axes per side, as in [[c35dde47|a square recurrent matrix]]), the normalization $alpha_P = n^(-(|cal(I) backslash op("inv")(P)|)/2)$ no longer eliminates $n$ from the coordinate-to-block map $bold(Phi)_n$. The reason is visible in [[7ee7cea7|the $k = 2$ canonical test vectors]]: the third copy of the standard representation $lambda = [1]$ is the projected diagonal matrix
```typst
bold(z)_([1], 2) = 1 / sqrt(1 - 2 slash n) lr([ op("Diag")(bold(h)) - 1/n (bold(h) bold(1)_n^top + bold(1)_n bold(h)^top) ]),
```
whose norm factor $(1 - 2/n)^(-1/2)$ and projection coefficients $-1/n$ depend non-monomially on $n$, and similarly the second trivial copy $bold(z)_(emptyset, 1) = (n - 1)^(-1/2)(bold(I)_n - frac(1, n) bold(J)_n)$ carries $(n - 1)^(-1/2)$. Consequently, for $k >= 2$, the dictionary matrix $bold(Phi)_n$ depends explicitly on $n$: holding the blocks $(bold(B)_lambda)_lambda$ fixed while varying $n$ requires changing the factor coordinates $bold(c)$ via [[be071dc0|width transport]], whereas holding $bold(c)$ fixed changes the blocks and distorts the operator's spectrum ([[3862bdb6|the naive surrogate pitfall]]).
