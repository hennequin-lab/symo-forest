# Worked example: a 3×4 weight matrix under three symmetry groups

Let $bold(C) in RR^(3 times 4)$ be a single weight matrix with $n = 3$ rows (hidden units) and $f = 4$ columns (input features), so its vectorization $bold(c) = op("vec")(bold(C))$ has $D = n f = 12$ entries. Any second-order operator $bold(S)$ on $bold(c)$ is a $12 times 12$ matrix with $D^2 = 144$ entries (or $frac(12 dot 13, 2) = 78$ independent entries if symmetric).

Index the rows of $bold(S)$ by $(m, alpha)$ and the columns by $(o, beta)$, with $m, o in {1, 2, 3}$ and $alpha, beta in {1, 2, 3, 4}$, so that $bold(S)$ is viewed as a $3 times 3$ block matrix of $4 times 4$ blocks $bold(S)_((m, dot), (o, dot)) in RR^(4 times 4)$.

## Three symmetry specifications on the same $3 times 4$ leaf

Depending on which symmetry group $cal(G)$ acts on the axes of $bold(C)$, [[33d479c5|index invariance]] constrains the $12 times 12$ matrix $bold(S) in cal(C)$ to three progressively smaller subspaces:

| symmetry group $cal(G)$ | `symo` axis specification | canonical form of $bold(S)_((m, alpha), (o, beta))$ | block structure of $bold(S) in RR^(12 times 12)$ | commutant dimension ($dim cal(C)$) |
| --- | --- | --- | --- | --- |
| row permutations $cal(S)_3$ | `[Perm 0; Id]` | $delta_(m o) bold(F)_(alpha beta) + 1_(m o) bold(G)_(alpha beta)$ | $bold(F) + bold(G)$ on the $3$ diagonal blocks; $bold(G)$ on all $6$ off-diagonal blocks | $2 f^2 = 32$ ($20$ if symmetric) |
| signed row permutations $cal(B)_3$ | signed `Perm 0`, `Id` | $delta_(m o) bold(F)_(alpha beta)$ | block-diagonal $op("Diag")(bold(F), bold(F), bold(F))$: one $4 times 4$ block repeated $3$ times | $f^2 = 16$ ($10$ if symmetric) |
| row & column permutations $cal(S)_3 times cal(S)_4$ | `[Perm 0; Perm 1]` | $a delta_(m o) delta_(alpha beta) + b delta_(m o) 1_(alpha beta) + c 1_(m o) delta_(alpha beta) + d 1_(m o) 1_(alpha beta)$ | $2$ scalar values in each diagonal block; $2$ scalar values in each off-diagonal block | $2 times 2 = 4$ ($4$ if symmetric) |

### Case 1: Row permutations $cal(S)_3$ ($k = 1, f = 4$)

Here $cal(G) = cal(S)_3$ permutes $m, o in {1, 2, 3}$ while leaving $alpha, beta in {1, 2, 3, 4}$ free. In the $3 times 3$ block layout:
```typst
bold(S) = mat(
  bold(F) + bold(G), bold(G), bold(G);
  bold(G), bold(F) + bold(G), bold(G);
  bold(G), bold(G), bold(F) + bold(G)
) = bold(I)_3 ⊗ bold(F) + bold(J)_3 ⊗ bold(G),
```
where $bold(F), bold(G) in RR^(4 times 4)$. Notice that $bold(S)$ is *dense* — all $144$ entries are in general non-zero — yet it is completely determined by the $32$ entries of $(bold(F), bold(G))$. When $bold(S) = cal(R)_2(bold(c), bold(c))$, both $bold(F)$ and $bold(G)$ are symmetric $4 times 4$ matrices, leaving $2 dot frac(4 dot 5, 2) = 20$ independent parameters.

### Case 2: Signed row permutations $cal(B)_3$

Enlarging the group on the row axis to $cal(B)_3 = {plus.minus 1}^3 times.r cal(S)_3$ (order $2^3 dot 3! = 48$) forces $bold(G) = bold(0)$ by [[2addfd8f|sign-flip annihilation]]. Thus $bold(S) = bold(I)_3 ⊗ bold(F) = op("Diag")(bold(F), bold(F), bold(F))$ is block-diagonal with a single $4 times 4$ matrix $bold(F)$ repeated along the diagonal ($16$ numbers, or $10$ if symmetric).

### Case 3: Product group $cal(S)_3 times cal(S)_4$ on both axes

When $cal(S)_3$ permutes the rows and an independent group $cal(S)_4$ permutes the columns (`[Perm 0; Perm 1]`), there are no free axes ($f = 1$). An entry $bold(S)_((m, alpha), (o, beta))$ can depend only on the two independent equality predicates $(m = o)$ and $(alpha = beta)$, giving $2 times 2 = 4$ basis tensors:
```typst
bold(S) = a (bold(I)_3 ⊗ bold(I)_4) + b (bold(I)_3 ⊗ bold(J)_4) + c (bold(J)_3 ⊗ bold(I)_4) + d (bold(J)_3 ⊗ bold(J)_4),
```
parameterized by four scalars $(a, b, c, d) in RR^4$.

At larger dimensions — for example, a $1000 times 784$ weight matrix ($n = 1000, f = 784, D = 7.84 times 10^5$) — the full matrix $bold(S)$ has $D^2 = 6.15 times 10^(11)$ entries, whereas its exact representation in $cal(C)$ requires only $2 f^2 = 1.23 times 10^6$ numbers under $cal(S)_(1000)$, $f^2 = 6.15 times 10^5$ numbers under $cal(B)_(1000)$, and $4$ numbers under $cal(S)_(1000) times cal(S)_(784)$. The block diagonalization of Case 1 is carried out in [[d47131ad|the Π/Π⊥ projector basis]].
