# Partial partitions, diagram terms, and Bell numbers

Let a single symmetric group $cal(G) = cal(S)_n$ act on the left space $W_L = V^(⊗k_L) ⊗ F_L$ ($k_L$ permuted axes of dimension $n$, free space $F_L$ of dimension $f_L$) and the right space $W_R = V^(⊗k_R) ⊗ F_R$ ($k_R$ permuted axes of dimension $n$, free space $F_R$ of dimension $f_R$).

An operator $bold(S) : W_R -> W_L$ is indexed by $k_L$ left unit indices $(i_1, dots, i_(k_L)) in {1, dots, n}^(k_L)$, $k_R$ right unit indices $(j_1, dots, j_(k_R)) in {1, dots, n}^(k_R)$, and the free indices $(alpha, beta) in {1, dots, f_L} times {1, dots, f_R}$. Collect the $k = k_L + k_R$ unit-index positions into an index set $cal(I)$ of cardinality $k = k_L + k_R$ (represented in `symo` by `Index.Left a` and `Index.Right b`).

## Set partitions and Bell numbers

By the same transitivity argument as in [[33d479c5|the $k_L = k_R = 1$ case]], invariance under $sigma in cal(S)_n$ acting simultaneously on all $k = k_L + k_R$ unit indices implies that $bold(S)$ can depend on the tuple $(i_1, dots, i_(k_L), j_1, dots, j_(k_R)) in {1, dots, n}^k$ only through which positions take equal values.

An equality pattern on $k$ positions is a **set partition** $pi = {B_1, dots, B_r}$ of the $k$-element set $cal(I)$ into non-empty disjoint blocks ($union.big_(s=1)^r B_s = cal(I)$). The number of set partitions of a $k$-element set is the **Bell number**
```typst
B_k = sum_(r=1)^k S(k, r),
```
where $S(k, r)$ is the Stirling number of the second kind (the number of partitions of $k$ elements into $r$ non-empty blocks). For the values of $k = k_L + k_R$ occurring in standard architectures:
- $k = 1$ (e.g. first-order average $cal(R)_1$ with $k_L = 1, k_R = 0$, or a weight-to-bias cross block): $B_1 = 1$.
- $k = 2$ (e.g. second-order average on one permuted axis, $k_L = k_R = 1$): $B_2 = S(2,1) + S(2,2) = 1 + 1 = 2$.
- $k = 3$ (e.g. cross block between a $k_L = 2$ recurrent matrix and a $k_R = 1$ bias or readout): $B_3 = 1 + 3 + 1 = 5$.
- $k = 4$ (e.g. diagonal block of a $k_L = k_R = 2$ square recurrent matrix $bold(W) in RR^(n times n)$):
  ```typst
  B_4 = S(4, 1) + S(4, 2) + S(4, 3) + S(4, 4) = 1 + 7 + 6 + 1 = 15.
  ```
- $k = 6$ (three permuted axes per side): $B_6 = 203$.

In the stable range $n >= k_L + k_R$ (and $n >= 2 max(k_L, k_R)$ for the two-sided block dictionary; see [[b50cfe81|semisimplicity and the stable range]]), the $B_(k_L + k_R)$ partition tensors are linearly independent and span the commutant of $V^(⊗k_R) -> V^(⊗k_L)$, which is the **partition algebra** $P_(k_L, k_R)(n)$ (Halverson & Ram, 2005).

## Partial partitions and normalized diagram terms (`Term.t`)

In the cumulative basis (the $delta / 1$ basis, as opposed to the disjoint non-equal indicator basis), a set partition $pi$ is encoded by enforcing equality within each block of size $|B| >= 2$ via Kronecker deltas, while leaving singleton blocks ${x}$ unconstrained (constant $1$ along axis $x$). Deleting all singleton blocks from $pi$ produces a **partial partition** $P = {B in pi : |B| >= 2}$ whose blocks all have cardinality at least $2$. Because the omitted elements of $cal(I)$ are uniquely recovered as singletons, this map is a bijection between set partitions of $cal(I)$ and partial partitions of $cal(I)$ with blocks of size $>= 2$.

In `symo` (`lib/term.ml`), a basis term is represented as
```ocaml
type t =
  { ties : Index.t list list  (* blocks B in P, each of length >= 2 *)
  ; free : Index.t list       (* free axes Id on left and right *)
  }
```
Denote by $op("inv")(P) = union.big_(B in P) B subset cal(I)$ the set of permuted axes involved in at least one tie, and let $cal(I)_"all"$ be the set of all left and right axes (both permuted and free). The unnormalized diagram tensor has entry $1$ whenever $i_x = i_y$ for all $x, y$ in the same tie block $B in P$ (and is constant along untied permuted axes $x in.not op("inv")(P)$). To keep basis norms well-scaled across widths, `Term.normalization` scales the tensor by the factor
```typst
alpha_P = lr((product_(x in cal(I)_"all" backslash (op("inv")(P) union F)) dim(x)))^(-1/2) = n^(-(|cal(I) backslash op("inv")(P)|) / 2),
```
where $F$ is the set of free axes and $|cal(I) backslash op("inv")(P)|$ is the number of untied permuted axes (singleton blocks of $pi$). Thus the normalized diagram tensor on the permuted axes is
```typst
bold(T)_P [bold(i), bold(j)] = alpha_P product_(B in P) delta_B (bold(i), bold(j)),
quad quad
delta_B (bold(i), bold(j)) = cases(
  1 & "if all indices in" B "are equal,",
  0 & "otherwise."
)
```
When multiple independent groups $g = 1, dots, G$ act on different subsets of axes of the leaf pair, each group generates its own $B_(k_(L,g) + k_(R,g))$ partial partitions, and `Compiler.basis_of_spec` takes their Cartesian product across groups, yielding $product_(g=1)^G B_(k_(L,g) + k_(R,g))$ diagram terms in total. Each term carries a factor matrix in $RR^(f_L times f_R)$ over the free axes. The inner products of these diagram tensors are computed symbolically in [[b81e35a1|the symbolic Gram matrix]].
