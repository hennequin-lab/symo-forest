# Crossing symmetry groups in an MLP-step recurrent network

Consider a discrete-time recurrent network whose state update is parameterized by a two-layer MLP with hidden dimension $n_h$ and state dimension $n_z$, driven by inputs $bold(x)_t in RR^(n_"in")$ and producing outputs $bold(y)_t in RR^(n_"out")$:
```typst
bold(z)_(t+1) = bold(W)_2 phi(bold(W)_1 bold(z)_t + bold(b)_1) + bold(b)_2 + bold(B) bold(x)_t,
quad quad
bold(y)_t = bold(W)_3 bold(z)_t + bold(b)_3,
```
where $phi : RR -> RR$ is an elementwise nonlinearity and the seven parameter leaves have shapes:
- $bold(W)_1 in RR^(n_h times n_z)$, $bold(b)_1 in RR^(n_h)$ (first transition layer),
- $bold(W)_2 in RR^(n_z times n_h)$, $bold(b)_2 in RR^(n_z)$ (second transition layer),
- $bold(B) in RR^(n_z times n_"in")$ (input projection), and
- $bold(W)_3 in RR^(n_"out" times n_z)$, $bold(b)_3 in RR^(n_"out")$ (linear readout).

## Two independent permutation groups: $cal(G)_h$ and $cal(G)_z$

Assuming the initial state is zero ($bold(z)_0 = bold(0)$) or transformed equivariantly, the sequence-to-sequence map $(bold(x)_1, dots, bold(x)_T) mapsto (bold(y)_1, dots, bold(y)_T)$ is invariant under the direct product group
```typst
cal(G) = cal(G)_h times cal(G)_z = cal(S)_(n_h) times cal(S)_(n_z),
quad quad
|cal(G)| = n_h ! dot n_z !,
```
generated by two structurally distinct actions:

1. **Step-internal hidden permutation $cal(G)_h = cal(S)_(n_h)$ (`Perm 0`).** For any permutation matrix $bold(P) in cal(S)_(n_h)$, replacing $(bold(W)_1, bold(b)_1, bold(W)_2) mapsto (bold(P) bold(W)_1, bold(P) bold(b)_1, bold(W)_2 bold(P)^top)$ leaves the single-step transition $bold(z)_t mapsto bold(z)_(t+1)$ pointwise unchanged because $bold(W)_2 bold(P)^top phi(bold(P)(bold(W)_1 bold(z)_t + bold(b)_1)) = bold(W)_2 phi(bold(W)_1 bold(z)_t + bold(b)_1)$. This symmetry is *local to the transition sub-network*: no tensor outside ${bold(W)_1, bold(b)_1, bold(W)_2}$ carries a $cal(G)_h$ index.
2. **Trajectory-wide state permutation $cal(G)_z = cal(S)_(n_z)$ (`Perm 1`).** Relabelling the coordinates of the recurrent state vector by $bold(z)_t mapsto bold(Q) bold(z)_t$ ($bold(Q) in cal(S)_(n_z)$) at every time step $t$ preserves the input–output map provided every tensor incident on $bold(z)_t$ transforms compatibly:
   ```typst
   (bold(W)_1, bold(W)_2, bold(b)_2, bold(B), bold(W)_3) mapsto (bold(W)_1 bold(Q)^top, bold(Q) bold(W)_2, bold(Q) bold(b)_2, bold(Q) bold(B), bold(W)_3 bold(Q)^top).
   ```
Indeed, by induction on $t$:
```typst
bold(z)'_(t+1)
= (bold(Q) bold(W)_2) phi((bold(W)_1 bold(Q)^top)(bold(Q) bold(z)_t) + bold(b)_1) + bold(Q) bold(b)_2 + (bold(Q) bold(B)) bold(x)_t
= bold(Q) bold(z)_(t+1),
```
and at the readout, $bold(y)'_t = (bold(W)_3 bold(Q)^top)(bold(Q) bold(z)_t) + bold(b)_3 = bold(y)_t$. Unlike $cal(G)_h$, $cal(G)_z$ is a *global computation symmetry* that couples five of the seven parameter leaves.

## Per-leaf representation and `symo` specification

| leaf $W_i$ | shape | group action $(bold(P), bold(Q)) in cal(S)_(n_h) times cal(S)_(n_z)$ | $(k_(i,h), k_(i,z), f_i)$ | `Symmetry.spec list` |
| --- | --- | --- | --- | --- |
| $bold(W)_1$ | $n_h times n_z$ | $bold(P) bold(W)_1 bold(Q)^top$ | $(1, 1, 1)$ | `[Perm 0; Perm 1]` |
| $bold(W)_2$ | $n_z times n_h$ | $bold(Q) bold(W)_2 bold(P)^top$ | $(1, 1, 1)$ | `[Perm 1; Perm 0]` |
| $bold(b)_1$ | $n_h$ | $bold(P) bold(b)_1$ | $(1, 0, 1)$ | `[Perm 0]` |
| $bold(b)_2$ | $n_z$ | $bold(Q) bold(b)_2$ | $(0, 1, 1)$ | `[Perm 1]` |
| $bold(B)$ | $n_z times n_"in"$ | $bold(Q) bold(B)$ | $(0, 1, n_"in")$ | `[Perm 1; Id]` |
| $bold(W)_3$ | $n_"out" times n_z$ | $bold(W)_3 bold(Q)^top$ | $(0, 1, n_"out")$ | `[Id; Perm 1]` |
| $bold(b)_3$ | $n_"out"$ | $bold(b)_3$ | $(0, 0, n_"out")$ | `[Id]` |

Notice that $cal(G)_h$ and $cal(G)_z$ **cross** on $bold(W)_1$ and $bold(W)_2$: each matrix has one axis permuted by $cal(G)_h$, the other axis permuted by $cal(G)_z$, and no free axis ($f_1 = f_2 = 1$). Even for a tiny instance with $n_h = 8, n_z = 6, n_"in" = 3, n_"out" = 2$ ($D = 48 + 48 + 8 + 6 + 18 + 12 + 2 = 142$ total parameters), the orbit size is $8! dot 6! = 40320 dot 720 = 29,030,400$.
