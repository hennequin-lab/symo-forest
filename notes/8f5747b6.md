# Gallery of orbit-average figures

Every figure in this vault is a vector SVG generated from `symo` tensors by `Hugin` via the OCaml project in `symo-forest/src/generate_figures.ml`:

```sh
cd src && dune exec ./generate_figures.exe -- -d ../figures
```

All ten figures use transparent paper and `currentColor` ink so they adapt live to both the dark and light themes of the vault.
