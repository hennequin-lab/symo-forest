# The first-order orbit average projects onto the invariant subspace

Let $cal(G)$ be a finite group acting on a Euclidean space $W = RR^D$ via an [[588b9727|orthogonal representation]] $rho : cal(G) -> O(W)$. The **invariant subspace** (or fixed-point subspace) of $W$ is
```typst
W^(cal(G)) = { bold(v) in W mid(|) rho(g) bold(v) = bold(v) quad forall g in cal(G) }.
```
The **first-order orbit average** is the linear operator $cal(R)_1 : W -> W$ defined by the uniform average over $cal(G)$:
```typst
cal(R)_1 (bold(v)) = bb(E)_(g in cal(G)) [ rho(g) bold(v) ] = 1/(|cal(G)|) sum_(g in cal(G)) rho(g) bold(v).
```

## Proposition (orthogonal projection onto $W^(cal(G))$)

$cal(R)_1$ is the orthogonal projection of $W$ onto $W^(cal(G))$. In particular:
1. $cal(R)_1(bold(v)) in W^(cal(G))$ for all $bold(v) in W$, and $cal(R)_1(bold(u)) = bold(u)$ for all $bold(u) in W^(cal(G))$;
2. $cal(R)_1$ is idempotent ($cal(R)_1^2 = cal(R)_1$) and self-adjoint ($cal(R)_1^top = cal(R)_1$);
3. For any $bold(v) in W$, the **orbit centroid** $bold(v)^star = cal(R)_1(bold(v))$ is the unique point in $W^(cal(G))$ closest to $bold(v)$ in Euclidean distance, with the Pythagorean decomposition $|bold(v)|_2^2 = |bold(v)^star|_2^2 + |bold(v) - bold(v)^star|_2^2$.

### Proof

1. **Image lies in $W^(cal(G))$.** For any $h in cal(G)$, left multiplication $g mapsto h g$ is a bijection of $cal(G)$ onto itself, so
   ```typst
   rho(h) cal(R)_1 (bold(v)) = 1/(|cal(G)|) sum_(g in cal(G)) rho(h g) bold(v) = 1/(|cal(G)|) sum_(g' in cal(G)) rho(g') bold(v) = cal(R)_1 (bold(v)).
   ```
2. **Fixes $W^(cal(G))$.** If $bold(u) in W^(cal(G))$, every summand satisfies $rho(g) bold(u) = bold(u)$, so $cal(R)_1(bold(u)) = bold(u)$. Combined with (1), this gives $cal(R)_1(cal(R)_1(bold(v))) = cal(R)_1(bold(v))$, i.e., $cal(R)_1^2 = cal(R)_1$.
3. **Self-adjointness.** Since $rho(g)$ is orthogonal, $rho(g)^top = rho(g)^(-1) = rho(g^(-1))$. Because inversion $g mapsto g^(-1)$ is a bijection of $cal(G)$,
   ```typst
   cal(R)_1^top = 1/(|cal(G)|) sum_(g in cal(G)) rho(g)^top = 1/(|cal(G)|) sum_(g in cal(G)) rho(g^(-1)) = cal(R)_1.
   ```
A self-adjoint idempotent operator on a Euclidean space is the orthogonal projection onto its image $W^(cal(G))$, from which (3) follows immediately since $bold(v) - bold(v)^star in (W^(cal(G)))^perp$. $square$

## Closed form for the symmetric group $cal(S)_n$

Let $cal(G) = cal(S)_n$ act on $V = RR^n$ by permutation matrices $bold(P)_sigma$. For each pair of indices $i, j in {1, dots, n}$, exact symmetry among the $n$ coordinates implies that $(n - 1)!$ of the $n!$ permutations send $j$ to $i$, so
```typst
bb(E)_(sigma in cal(S)_n) [ bold(P)_sigma ] = (n - 1)! / n! bold(J)_n = 1/n bold(1)_n bold(1)_n^top =: bold(Pi),
```
where $bold(1)_n = (1, dots, 1)^top in RR^n$ and $bold(J)_n = bold(1)_n bold(1)_n^top$ is the $n times n$ all-ones matrix.

Consequently, on a matrix leaf $bold(W) in RR^(n times f)$ whose row axis is permuted by $cal(S)_n$ and whose column axis is free ($k = 1$, $rho(sigma) = bold(P)_sigma ⊗ bold(I)_f$),
```typst
(cal(R)_1 (bold(W)))_(i j) = (bold(Pi) bold(W))_(i j) = 1/n sum_(r=1)^n bold(W)_(r j).
```
The average over all $n!$ permutations replaces every row of $bold(W)$ by the mean row in $O(n f)$ operations. In `symo`, $cal(R)_1$ is compiled as the special case of the commutant projection where the right-hand tensor space is trivial ($k_R = 0$, specified via `Symmetry.Absent` in `Orbit.First_order`; see [[dc31c6c2|symmetry specifications]]). The second-order expectation $bb(E)[bold(P)_sigma ⊗ bold(P)_sigma]$ is derived in [[273c28e5|moments of a random permutation]].
