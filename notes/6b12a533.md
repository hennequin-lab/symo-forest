# Function invariance implies gradient equivariance

Let $cal(L) : W -> RR$ be a differentiable function on a Euclidean parameter space $W = RR^D$, and let $cal(G)$ act on $W$ via an [[588b9727|orthogonal representation]] $rho : cal(G) -> O(W)$ such that $cal(L)$ is $cal(G)$-invariant:
```typst
cal(L)(rho(g) bold(w)) = cal(L)(bold(w)) quad forall g in cal(G), bold(w) in W.
```
For any point $bold(w) in W$, its **orbit** under $cal(G)$ is the set
```typst
cal(G) bold(w) = { rho(g) bold(w) mid(|) g in cal(G) } subset W.
```
By definition, $cal(L)$ is constant on $cal(G) bold(w)$, so the orbit is contained in a single level set of $cal(L)$.

## Proposition (equivariance of the gradient and Hessian)

For every $g in cal(G)$ and $bold(w) in W$, the gradient $nabla cal(L) : W -> W$ and (when $cal(L)$ is twice differentiable) the Hessian $nabla^2 cal(L) : W -> RR^(D times D)$ satisfy
```typst
nabla cal(L)(rho(g) bold(w)) = rho(g) nabla cal(L)(bold(w)),
quad quad
nabla^2 cal(L)(rho(g) bold(w)) = rho(g) nabla^2 cal(L)(bold(w)) rho(g)^top.
```

### Proof

Fix $g in cal(G)$ and define the linear map $phi_g (bold(w)) = rho(g) bold(w)$, whose Jacobian matrix at every point is $dif phi_g (bold(w)) = rho(g)$. Differentiating both sides of the invariance identity $(cal(L) compose phi_g)(bold(w)) = cal(L)(bold(w))$ with respect to $bold(w)$ by the chain rule yields
```typst
rho(g)^top nabla cal(L)(rho(g) bold(w)) = nabla cal(L)(bold(w)).
```
Because $rho(g)$ is orthogonal, $rho(g)^top = rho(g)^(-1)$. Multiplying both sides on the left by $rho(g)$ gives
```typst
nabla cal(L)(rho(g) bold(w)) = rho(g) nabla cal(L)(bold(w)).
```
Differentiating a second time with respect to $bold(w)$ gives $nabla^2 cal(L)(rho(g) bold(w)) rho(g) = rho(g) nabla^2 cal(L)(bold(w))$, and right-multiplying by $rho(g)^top = rho(g)^(-1)$ yields the Hessian identity. $square$

## Consequences for orbit averages

1. **One backward pass determines the entire gradient orbit.** Evaluating $bold(g) = nabla cal(L)(bold(w))$ at a single parameter vector $bold(w)$ immediately specifies the gradient $nabla cal(L)(rho(g) bold(w)) = rho(g) bold(g)$ at all $|cal(G)|$ points of the orbit without additional backward passes.
2. **Orbit moments reduce to group averages of a single vector.** The first and second moments of the gradient over the orbit $cal(G) bold(w)$ are
   ```typst
   bb(E)_(g in cal(G)) [ nabla cal(L)(rho(g) bold(w)) ] = bb(E)_(g in cal(G)) [ rho(g) bold(g) ] = cal(R)_1 (bold(g)),
   ```
   ```typst
   bb(E)_(g in cal(G)) [ nabla cal(L)(rho(g) bold(w)) nabla cal(L)(rho(g) bold(w))^top ] = bb(E)_(g in cal(G)) [ (rho(g) bold(g)) (rho(g) bold(g))^top ] = cal(R)_2 (bold(g), bold(g)).
   ```
   Thus the exact statistics of $nabla cal(L)$ across the entire symmetry orbit are the algebraic projections $cal(R)_1(bold(g))$ and $cal(R)_2(bold(g), bold(g))$ of the single gradient vector $bold(g)$ ([[6226b6f2|first-order projection]], [[8eb163bd|second-order projection]]).
3. **At an invariant point, the gradient is invariant.** If $bold(w)^star in W^(cal(G))$ is a fixed point of the group ($rho(g) bold(w)^star = bold(w)^star$ for all $g in cal(G)$, such as the orbit centroid $bold(w)^star = cal(R)_1(bold(w))$), then $nabla cal(L)(bold(w)^star) = rho(g) nabla cal(L)(bold(w)^star)$ for all $g in cal(G)$, so $nabla cal(L)(bold(w)^star) in W^(cal(G))$ and $nabla^2 cal(L)(bold(w)^star) in cal(C)(W, W)$.
