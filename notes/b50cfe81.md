# Semisimplicity of the partition algebra and the stable range n ≥ 2k

The dimension counts, multiplicities $m_lambda$, and invertibility of the block dictionary in [[35cc480f|the isotypic decomposition]] and [[46af9ff5|the Wedderburn theorem]] require the permuted axis dimension $n$ to be large enough that all equality-pattern diagrams are linearly independent and all stable Specht modules exist.

## Proposition (semisimplicity threshold and the stable range)

For a permutation group $cal(S)_n$ acting on $k_L$ left axes and $k_R$ right axes of dimension $n$:
1. The $B_(k_L + k_R)$ diagram tensors ${bold(T)_P}$ in $cal(C)(V^(⊗k_R), V^(⊗k_L))$ are linearly independent (and hence the [[b81e35a1|Gram matrix]] $bold(G)$ is strictly positive definite) if and only if $n >= k_L + k_R$.
2. For a diagonal pair $k_L = k_R = k$, the partition algebra $P_k(n)$ is semisimple and isomorphic to $⊕_lambda op("End")(cal(M)_lambda)$ with the stable multiplicities $m_lambda$ if and only if
   ```typst
   n >= 2 k.
   ```
3. In general, for both sides $V^(⊗k_L)$ and $V^(⊗k_R)$ to individually carry their stable kind lists and multiplicities — so that canonical test vectors can be constructed uniformly on each side (`Kind.test_vectors`) — it suffices that $n >= 2 k_L$ and $n >= 2 k_R$, i.e., $n >= 2 max(k_L, k_R)$ (`Kind.stable_dim ~k = 2 * k`).

### Concrete thresholds

- $k = 0$ (no permuted axes): $n >= 0$ (unconstrained).
- $k = 1$ (one permuted axis per side): **$n >= 2$**.
- $k = 2$ (two tied axes per side, e.g. $bold(W) in RR^(n times n)$ in a vanilla RNN): **$n >= 4$**.
- $k = 3$ (three tied axes per side): **$n >= 6$**.

## What fails when $n < 2k$

By the pigeonhole principle, if an index tuple $(i_1, dots, i_(2k)) in {1, dots, n}^(2k)$ draws from fewer than $2k$ available unit labels ($n < 2k$), then at least two indices in every tuple *must* coincide: there exist no tuples of $2k$ mutually distinct indices. Consequently, the disjoint indicator tensor for the all-distinct partition $S(2k, 2k)$ vanishes identically, creating a linear dependency among the $B_(2k)$ cumulative diagram tensors ${bold(T)_P}$:

- **For $k = 1$ at $n = 1$:** $bold(I)_1 = bold(J)_1 = [1]$, so the $B_2 = 2$ diagram tensors coincide ($op("rank")(bold(G)) = 1 < 2$), and the standard carrier $cal(S)_([1])$ has dimension $d_([1])(1) = 1 - 1 = 0$.
- **For $k = 2$ at $n = 3$:** The carrier dimension of the symmetric-square kind $lambda = [2]$ in [[35cc480f|the $k = 2$ isotypic table]] is $d_([2])(n) = frac(n(n - 3), 2)$, which vanishes at $n = 3$ ($d_([2])(3) = 0$). Only $14$ of the $B_4 = 15$ diagram tensors remain linearly independent ($op("rank")(bold(G)) = 14$), and the 4-cycle test vector for $lambda = [2]$ cannot be formed because it requires $4$ distinct indices ${0, 1, 2, 3}$.
- **For $k = 2$ at $n = 2$:** Both $d_([2])(2) = -1$ (absent) and the third copy of the standard kind $[1]$ collapse, leaving only $8$ linearly independent operators out of $15$ ($d_emptyset m_emptyset^2 + d_([1]) m_([1])^2 + d_([1,1]) m_([1,1])^2$ drops to $2^2 + 2^2 = 8$).

Because the block dictionary $bold(P)$ and width transport $tau_(n -> n')$ rely on the bijective correspondence between factor lists and stable Wedderburn blocks, `Kind.check_stable` verifies $n >= 2k$ at compile time and raises `Invalid_argument` if a permuted axis violates the stable range. Free axes (`Symmetry.Id`) have $k = 0$ and are unconstrained.
