# The symo compiler and orbit architecture — trailhead

`symo` (`murder/packages/symo`) is the OCaml implementation of the commutant compiler, orbit projections $cal(R)_1$ and $cal(R)_2$, Wedderburn block dictionary, and width transport on top of the Raven stack (`nx` tensors, `rune` for autodiff and JIT compilation, and `ppx_ptree` for parameter trees).

Every algebraic object in the vault corresponds directly to an OCaml module in `murder/packages/symo/lib/`. Compile-time operations (enumerating partial-partition diagrams, evaluating the symbolic Gram matrix on the partition lattice, Cholesky factorization, and constructing the canonical test-vector pairing table $bold(P)$ and its pseudoinverse $bold(P)^dagger$) execute once when the functor `Symo.Orbit.Make (M)` is instantiated. All runtime operations (`estimate_factors`, `apply_block`, `to_blocks`, `of_blocks`, `transport`) are pure compositions of `Nx` tensor primitives (`einsum`, `reshape`, `broadcast_to`, `solve_triangular`) with static shapes and no host value reads, so they trace under `Rune.jit` without retracing.
