# Two-sided conjugation W ↦ QWQᵀ in recurrent networks

Consider a single-layer ("vanilla") recurrent network with state $bold(z)_t in RR^n$, input $bold(x)_t in RR^(n_"in")$, and output $bold(y)_t in RR^(n_"out")$:
```typst
bold(z)_(t+1) = phi(bold(W) bold(z)_t + bold(U) bold(x)_t + bold(b)),
quad quad
bold(y)_t = bold(V) bold(z)_t,
```
where $bold(W) in RR^(n times n)$ is the square recurrent transition matrix, $bold(U) in RR^(n times n_"in")$, $bold(b) in RR^n$, and $bold(V) in RR^(n_"out" times n)$.

Under a permutation $bold(z)_t mapsto bold(Q) bold(z)_t$ ($bold(Q) = bold(P)_sigma in cal(S)_n$) of the $n$ recurrent state units, invariance of the trajectory requires
```typst
(bold(W), bold(U), bold(b), bold(V)) mapsto (bold(Q) bold(W) bold(Q)^top, bold(Q) bold(U), bold(Q) bold(b), bold(V) bold(Q)^top).
```
Unlike the transition matrices $bold(W)_1, bold(W)_2$ of [[a97e31ca|the MLP-step RNN]] — whose rows and columns were transformed by *two independent groups* $cal(G)_h times cal(G)_z$ — both the rows and the columns of $bold(W) in RR^(n times n)$ are transformed by **the same permutation matrix $bold(Q) in cal(S)_n$**. On the vectorization $op("vec")(bold(W)) in RR^(n^2) = V ⊗ V$, the group acts by the tensor square ($k = 2, f = 1$):
```typst
rho_(bold(W))(sigma) = bold(P)_sigma ⊗ bold(P)_sigma,
quad quad
"Symmetry specification: " "[Perm 0; Perm 0]".
```

## Fifteen equality patterns ($B_4 = 15$) and eleven symmetric parameters

Let $bold(S) = cal(R)_2(op("vec")(bold(A)), op("vec")(bold(B))) in cal(C)(V^(⊗2), V^(⊗2))$ be a second-order orbit average on the recurrent leaf $bold(W)$, indexed by row pair $(m, n) in {1, dots, n}^2$ and column pair $(o, p) in {1, dots, n}^2$. Invariance under conjugation by $bold(P)_sigma ⊗ bold(P)_sigma$ requires
```typst
bold(S)_((m,n),(o,p)) = bold(S)_((sigma(m), sigma(n)), (sigma(o), sigma(p))) quad forall sigma in cal(S)_n.
```
Because a single permutation $sigma$ acts on all four indices $(m, n, o, p)$ simultaneously, equality can hold between *any* subset of ${m, n, o, p}$ — including cross-axis equalities such as $m = n$ (diagonal of left $bold(W)$), $o = p$ (diagonal of right $bold(W)$), or $m = p$ and $n = o$ (transpose matching between $bold(W)$ and $bold(W)^top$) that were forbidden under two independent groups $cal(S)_(n_1) times cal(S)_(n_2)$.

By [[a0bb3d95|the Bell-number count]], the four-element index set ${L_0, L_1, R_0, R_1} = {m, n, o, p}$ has
```typst
B_4 = S(4, 1) + S(4, 2) + S(4, 3) + S(4, 4) = 1 + 7 + 6 + 1 = 15
```
set partitions, corresponding to $15$ partial partitions (`Term.t`) grouped by their tie structure:
1. **$1$ four-way tie ($S(4,1) = 1$):** ${{m, n, o, p}}$ ($m = n = o = p$).
2. **$4$ three-way ties ($4$ of $S(4,2)$):** ${{m, n, o}}, {{m, n, p}}, {{m, o, p}}, {{n, o, p}}$.
3. **$3$ pairs of two-way ties ($3$ of $S(4,2)$):** ${{m, n}, {o, p}}, {{m, o}, {n, p}}, {{m, p}, {n, o}}$.
4. **$6$ single two-way ties ($S(4,3) = 6$):** ${{m, n}}, {{o, p}}, {{m, o}}, {{n, p}}, {{m, p}}, {{n, o}}$.
5. **$1$ empty tie ($S(4,4) = 1$):** $emptyset$ (the all-ones tensor).

For any state width $n >= 4$ ([[b50cfe81|the stable range $n >= 2k$]]), these $15$ diagram tensors are linearly independent and span $cal(C)(V^(⊗2), V^(⊗2))$. Thus any invariant operator on $bold(W) in RR^(n times n)$ — an $n^2 times n^2$ matrix with $n^4$ entries (e.g. $6.4 times 10^7$ entries at $n = 89$ or $4.1 times 10^(12)$ entries at $n = 1420$) — takes at most **$15$ distinct entry values**, with zero variance within each equality-pattern class.

When $bold(S) = cal(R)_2(op("vec")(bold(A)), op("vec")(bold(A)))$ is symmetric ($bold(S)^top = bold(S)$, exchanging $(m, n) arrow.l.r (o, p)$), four pairs of asymmetric partitions must carry equal coefficients:
```typst
{{m, n, o}} <-> {{m, o, p}}, quad
{{m, n, p}} <-> {{n, o, p}}, quad
{{m, n}} <-> {{o, p}}, quad
{{m, p}} <-> {{n, o}},
```
while the remaining $7$ partitions are self-transpose. Because $f = 1$, [[4875a459|symmetric component bundling]] is complete and reduces the parameter count from $15$ to $7 + 4 = 11$ independent scalars at any width $n >= 4$.

## Extension to gated architectures (GRU and LSTM)

In a Gated Recurrent Unit (GRU) or Long Short-Term Memory (LSTM) cell, each gate $g in {"reset", "update", "candidate"}$ (or ${"input", "forget", "cell", "output"}$) has its own square recurrent matrix $bold(W)_g in RR^(n times n)$, input matrix $bold(U)_g in RR^(n times n_"in")$, and bias $bold(b)_g in RR^n$, all transformed simultaneously by the same state permutation $bold(Q) in cal(S)_n$:
```typst
bold(W)_g mapsto bold(Q) bold(W)_g bold(Q)^top, quad
bold(U)_g mapsto bold(Q) bold(U)_g, quad
bold(b)_g mapsto bold(Q) bold(b)_g.
```
In the resulting multi-leaf mosaic:
- Every diagonal gate tile $cal(R)_2(bold(W)_g, bold(W)_g)$ is compressed to $11$ symmetric scalars, and every cross-gate tile $cal(R)_2(bold(W)_g, bold(W)_(g'))$ ($g != g'$) is compressed to $B_4 = 15$ scalars.
- Every gate-to-bias cross tile $cal(R)_2(bold(W)_g, bold(b)_(g'))$ ($k_L = 2, k_R = 1$) is compressed to $B_(2+1) = B_3 = 5$ scalars (or $5 n_"in"$ for $cal(R)_2(bold(W)_g, bold(U)_(g'))$).

How the $15$ parameters of a $k = 2$ tile split into four irreducible blocks of sizes $2 times 2, 3 times 3, 1 times 1, 1 times 1$ ($2^2 + 3^2 + 1^2 + 1^2 = 15$, and $3 + 6 + 1 + 1 = 11$ when symmetric) is proved in [[35cc480f|the isotypic decomposition of $V^(⊗k)$]].
