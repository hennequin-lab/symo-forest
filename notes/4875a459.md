# Symmetric component bundling and the Λ²W ⊗ Λ²F completeness condition

On a diagonal leaf pair ($W_L = W_R = W = W_"perm" ⊗ F$, where $W_"perm" = V^(⊗k)$ and $dim F = f$), the second-order orbit average of a single vector $bold(S) = cal(R)_2(bold(u), bold(u))$ is a symmetric matrix ($bold(S)^top = bold(S)$). It lies in the **symmetric commutant**
```typst
cal(C)_"sym" (W) = { bold(S) in cal(C)(W, W) mid(|) bold(S)^top = bold(S) }.
```
For each diagram term $bold(T)_P$ on $W_"perm"$ ([[a0bb3d95|partial partitions and diagram terms]]), its transpose $bold(T)_P^top$ is the diagram term $bold(T)_(P^top)$ obtained by swapping left and right axis indices (`Index.Left i` $arrow.l.r$ `Index.Right i`). A natural optimization (`Compiler.bundle_transposes`) is to pair each asymmetric term $bold(T)_P != bold(T)_P^top$ with its transpose into a single symmetric component (`Component.Sum`):
```typst
bold(C)_({P, P^top}) = bold(T)_P + bold(T)_(P^top).
```
For $k = 2$ (where $B_4 = 15$), $7$ of the $15$ partial partitions are self-transpose ($bold(T)_P^top = bold(T)_P$) and the remaining $8$ pair up into $4$ transposed pairs, reducing the number of components from $15$ to $7 + 4 = 11$.

However, bundling $bold(T)_P + bold(T)_P^top$ only spans $cal(C)_"sym"(W)$ under a specific algebraic condition on $(k, f)$, checked in `Compiler.symmetric_basis_is_complete`.

## Proposition (completeness of transpose-bundled components)

Decompose the space of all symmetric operators on $W = W_"perm" ⊗ F$ into symmetric and skew-symmetric tensor parts:
```typst
op("Sym")^2 (W_"perm" ⊗ F)
= lr([op("Sym")^2 (W_"perm") ⊗ op("Sym")^2 (F)]) ⊕ lr([Lambda^2 (W_"perm") ⊗ Lambda^2 (F)]),
```
because the Kronecker product of two symmetric matrices is symmetric, and the Kronecker product of two skew-symmetric matrices is also symmetric ($(bold(A) ⊗ bold(B))^top = bold(A)^top ⊗ bold(B)^top = (-bold(A)) ⊗ (-bold(B)) = bold(A) ⊗ bold(B)$). Taking the intersection with the commutant $cal(C)(W, W) = cal(C)(W_"perm") ⊗ op("End")(F)$ gives
```typst
cal(C)_"sym" (W)
= lr([cal(C)_"sym" (W_"perm") ⊗ op("Sym")^2 (F)]) ⊕ lr([cal(C)_"skew" (W_"perm") ⊗ Lambda^2 (F)]),
```
where $cal(C)_"sym"(W_"perm") = {bold(A) in cal(C)(W_"perm") : bold(A)^top = bold(A)}$ and $cal(C)_"skew"(W_"perm") = {bold(A) in cal(C)(W_"perm") : bold(A)^top = -bold(A)}$.

By contrast, bundling the permuted diagram terms into $bold(T)_P + bold(T)_P^top$ spans $cal(C)_"sym"(W_"perm")$ while attaching an arbitrary $f times f$ factor matrix in $op("End")(F) = op("Sym")^2(F) ⊕ Lambda^2(F)$, so the bundled components span $cal(C)_"sym"(W_"perm") ⊗ op("End")(F)$. Consequently, the bundled basis contains $cal(C)_"sym"(W)$ if and only if the skew-symmetric summand vanishes:
```typst
cal(C)_"skew" (W_"perm") ⊗ Lambda^2 (F) = {bold(0)}.
```
This holds in either of two cases:
1. **$f = 1$ (no non-trivial free axis).** When $dim F = 1$, every $1 times 1$ matrix is symmetric, so $Lambda^2(F) = {0}$ and $dim cal(C)_"sym"(W) = dim cal(C)_"sym"(W_"perm")$ ($11$ for $k = 2$).
2. **$k <= 1$ for every group acting on the leaf.** When each group permutes at most one axis of the leaf ($k_g <= 1$), every diagram term in $P_1(n) = op("span"){bold(I)_n, bold(J)_n}$ is already symmetric ($bold(I)_n^top = bold(I)_n$, $bold(J)_n^top = bold(J)_n$), so $cal(C)_"skew"(W_"perm") = {0}$ (equivalently, every isotypic multiplicity is $m_lambda = 1$; see [[35cc480f|isotypic decomposition]]).

When **both $f > 1$ and some group has $k >= 2$ on the leaf**, $dim Lambda^2(F) = frac(f(f - 1), 2) >= 1$ and $dim cal(C)_"skew"(W_"perm") = sum_lambda frac(m_lambda(m_lambda - 1), 2) >= 1$ (for $k = 2$, $m_emptyset = 2$ and $m_([1]) = 3$ contribute $1 + 3 = 4$ linearly independent skew-symmetric intertwiners $bold(T)_P - bold(T)_(P^top)$). A symmetric operator $bold(S) = cal(R)_2(bold(u), bold(u))$ can then have non-zero components of the form $(bold(T)_P - bold(T)_(P^top)) ⊗ bold(K)$ with $bold(K)^top = -bold(K) in Lambda^2(F)$. In that regime, `Compiler.compile ~symmetric:true` automatically falls back to the unbundled basis of size $B_(2k)$ ($15$ components for $k = 2$) so that the projection onto $cal(C)(W, W)$ remains exact and positive semidefiniteness is preserved.
