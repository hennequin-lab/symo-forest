# Why evaluating fixed factor coordinates at a surrogate width changes the operator

Given a factor coordinate list $bold(c) = (c_1, dots, c_d)$ estimated at width $n$, a tempting shortcut — used in early surrogate implementations before the block dictionary was introduced — is to evaluate the **same numeric coordinate vector $bold(c)$** in the diagram basis ${bold(T)_k(n')}$ at a smaller "surrogate" width $n' < n$, diagonalize the small dense matrix $tilde(bold(S))_(n') = sum_(k=1)^d c_k bold(T)_k(n')$, and plug the resulting factor coordinates back into ${bold(T)_k(n)}$.

Comparing this shortcut against [[be071dc0|width transport]] $tau_(n -> n') = bold(Phi)_(n')^(-1) compose bold(Phi)_n$ makes the error precise:
- **Exact transport $tau_(n -> n')$** changes the coordinates $bold(c)_(n') = bold(Phi)_(n')^(-1)(bold(Phi)_n(bold(c)_n))$ so that the Wedderburn blocks $bold(B)_lambda = bold(Phi)_(n')(bold(c)_(n')) = bold(Phi)_n(bold(c)_n)$ remain invariant.
- **Naive coordinate reuse ($bold(c)_(n') = bold(c)_n$)** holds the coordinates fixed while changing the dictionary $bold(Phi)_n -> bold(Phi)_(n')$, thereby creating a *different operator* with altered blocks $tilde(bold(B))_lambda = bold(Phi)_(n')(bold(c)_n) != bold(B)_lambda$ and a shifted spectrum.

## Why $k = 1$ hides the bug and $k = 2$ exposes it

As shown in [[790ac25a|factor coordinates versus Wedderburn blocks]], for $k = 1$ the $1/n$ normalization of $bold(T)_emptyset = frac(1, n) bold(J)_n$ makes the $2 times 2$ dictionary $bold(Phi)_n$ independent of $n$ ($bold(B)_emptyset = bold(C)_emptyset + bold(C)_([1])$, $bold(B)_([1]) = bold(C)_([1])$). Thus for $k = 1$ alone, $tau_(n -> n') = op("id")$, so naive coordinate reuse accidentally coincides with exact transport.

For $k = 2$ (two tied permuted axes, $f = 1$, $d = 11$ symmetric components, and four Wedderburn blocks of sizes $2 times 2$, $3 times 3$, $1 times 1$, $1 times 1$, giving $2 + 3 + 1 + 1 = 7$ distinct eigenvalues), $bold(Phi)_n$ depends non-trivially on $n$ because the normalized test vectors $bold(z)_(emptyset, 1)$ and $bold(z)_([1], 2)$ and the normalized diagram tensors $bold(T)_P(n)$ scale with different powers of $n$ and $n - 1$ ([[7ee7cea7|explicit $k = 2$ test vectors]]).

### Quantitative spectrum drift under fixed coordinates ($k = 2$)

In `murder/packages/symo/doc/transport.typ` (§6.2–6.3) and `test/test_blocks.ml`, a fixed symmetric factor vector $bold(c) in RR^(11)$ is evaluated directly at widths $n in {5, 6, 8, 12}$ without transport:

| width $n$ | $op("tr")(tilde(bold(S))_n)$ | $7$ distinct eigenvalues of $sum_(k=1)^(11) c_k bold(T)_k (n)$ |
| --- | --- | --- |
| $5$ | $-36.445$ | $-4.472, quad -3.552, quad -2.927, quad bold(-2.399), quad bold(-1.089), quad 2.097, quad 6.844$ |
| $6$ | $-56.734$ | $-4.476, quad -3.611, quad -3.003, quad bold(-2.399), quad bold(-1.089), quad 1.961, quad 6.946$ |
| $8$ | $-108.04$ | $-4.483, quad -3.671, quad -3.107, quad bold(-2.399), quad bold(-1.089), quad 1.770, quad 7.220$ |
| $12$ | $-253.19$ | $-4.494, quad -3.674, quad -3.227, quad bold(-2.399), quad bold(-1.089), quad 1.542, quad 7.899$ |

Observe the pattern:
1. Exactly **two** of the seven distinct eigenvalues ($-2.399$ and $-1.089$, belonging to the $1 times 1$ symmetric-square block $bold(B)_([2])$ and the $1 times 1$ antisymmetric block $bold(B)_([1,1])$) remain invariant across $n$, because those $1 times 1$ blocks pair only against diagram terms with zero untied axes ($alpha_P = 1$).
2. The remaining **five** distinct eigenvalues — the two eigenvalues of the $2 times 2$ trivial block $bold(B)_emptyset$ and the three eigenvalues of the $3 times 3$ standard block $bold(B)_([1])$ — **drift with $n$** as the untied-axis normalizations shift the entries of $bold(Phi)_n(bold(c))$.
3. Conversely, when $bold(c)_5$ is mapped to $bold(c)_8 = tau_(5 -> 8)(bold(c)_5)$ via `Blocks.transport`, the $11$ coordinates are rescaled by factors ranging between $0.43$ and $1.25$, and all seven distinct eigenvalues at $n = 8$ match those at $n = 5$ to machine precision.

With [[93e6cfab|the block functional calculus]], no surrogate width $n'$ is ever needed to evaluate matrix functions $f(bold(S))$: the Wedderburn blocks $bold(B)_lambda = bold(Phi)_n(bold(c)_n)$ are already of width-independent size $m_lambda f$ at the model's native width $n$.
