# First and second moments of a random permutation matrix

Let $sigma in cal(S)_n$ be drawn uniformly at random from the symmetric group on $n >= 2$ elements, and let $bold(P)_sigma in {0, 1}^(n times n)$ be its permutation matrix, with entries $(bold(P)_sigma)_(m a) = delta_(m, sigma(a))$ for $m, a in {1, dots, n}$.

As established in [[6226b6f2|the first-order projection]], the first moment is
```typst
bb(E)_(sigma in cal(S)_n) [ (bold(P)_sigma)_(m a) ] = 1/n,
quad "or in matrix form," quad
bb(E)_(sigma in cal(S)_n) [ bold(P)_sigma ] = 1/n bold(J)_n = bold(Pi),
```
where $bold(J)_n = bold(1)_n bold(1)_n^top$ is the $n times n$ all-ones matrix and $bold(Pi) = frac(1, n) bold(J)_n$ is the orthogonal projector onto $op("span")(bold(1)_n)$.

## Derivation of the second moment $bb(E)[bold(P)_sigma ⊗ bold(P)_sigma]$

For the second-order orbit average on a single permuted axis ($k_L = k_R = 1$), we require the four-index expectation
```typst
bb(E)_(sigma in cal(S)_n) [ (bold(P)_sigma)_(m a) (bold(P)_sigma)_(o b) ] = bb(P)_(sigma in cal(S)_n) (sigma(a) = m "and" sigma(b) = o)
```
for indices $m, o, a, b in {1, dots, n}$. Because every $sigma in cal(S)_n$ is a bijection, the probability splits into four mutually exclusive cases according to the two equality indicators $delta_(m o)$ and $delta_(a b)$:

1. **Same input, same output ($a = b$ and $m = o$).** The condition reduces to $sigma(a) = m$, which holds for $(n - 1)!$ of the $n!$ permutations, giving probability $frac(1, n)$.
2. **Same input, different outputs ($a = b$ and $m != o$).** Since $sigma$ is a function, $sigma(a)$ cannot equal both $m$ and $o$; the probability is $0$.
3. **Different inputs, same output ($a != b$ and $m = o$).** Since $sigma$ is injective, $sigma(a)$ and $sigma(b)$ cannot both equal $m$; the probability is $0$.
4. **Different inputs, different outputs ($a != b$ and $m != o$).** Exactly $(n - 2)!$ permutations map $a mapsto m$ and $b mapsto o$, giving probability $frac((n - 2)!, n!) = frac(1, n(n - 1))$.

Combining all four cases into a single algebraic expression yields
```typst
bb(E)_(sigma in cal(S)_n) [ (bold(P)_sigma)_(m a) (bold(P)_sigma)_(o b) ]
= 1/n delta_(m o) delta_(a b) + 1/(n(n - 1)) (1 - delta_(m o))(1 - delta_(a b)).
```

## Expansion in the orthogonal projectors $bold(Pi)$ and $bold(Pi)_perp$

Define the complementary orthogonal projectors on $RR^n$:
```typst
bold(Pi) = 1/n bold(J)_n, quad quad
bold(Pi)_perp = bold(I)_n - bold(Pi) = bold(I)_n - 1/n bold(J)_n,
```
which satisfy $bold(Pi)^2 = bold(Pi)$, $bold(Pi)_perp^2 = bold(Pi)_perp$, $bold(Pi) bold(Pi)_perp = bold(0)$, $op("tr")(bold(Pi)) = 1$, and $op("tr")(bold(Pi)_perp) = n - 1$. Expanding $1 - delta_(m o) = 1_(m o) - delta_(m o)$ and substituting the matrix entries $delta_(m o) = (bold(Pi) + bold(Pi)_perp)_(m o)$ and $1_(m o) = n bold(Pi)_(m o)$ (so $1_(m o) - delta_(m o) = (n - 1) bold(Pi)_(m o) - (bold(Pi)_perp)_(m o)$) diagonalizes the expectation into a sum of two tensor-square projectors:
```typst
bb(E)_(sigma in cal(S)_n) [ (bold(P)_sigma)_(m a) (bold(P)_sigma)_(o b) ]
= bold(Pi)_(m o) bold(Pi)_(a b) + 1/(n - 1) (bold(Pi)_perp)_(m o) (bold(Pi)_perp)_(a b).
```
Verify this identity by expanding the right-hand side:
- When $m = o$ and $a = b$: $bold(Pi)_(m m) = frac(1, n)$ and $(bold(Pi)_perp)_(m m) = frac(n - 1, n)$, so $frac(1, n^2) + frac(1, n-1)frac((n-1)^2, n^2) = frac(1, n)$.
- When $m = o$ and $a != b$: $(bold(Pi)_perp)_(a b) = -frac(1, n)$, so $frac(1, n^2) + frac(1, n-1)frac(n-1, n)lr((-frac(1, n))) = 0$.
- When $m != o$ and $a != b$: $frac(1, n^2) + frac(1, n-1)lr((-frac(1, n)))^2 = frac(n - 1 + 1, n^2(n - 1)) = frac(1, n(n - 1))$.

Applying this formula to an outer product $bold(X) in RR^(n times n)$ immediately gives the action of the twirl $cal(T)(bold(X)) = bb(E)_sigma[bold(P)_sigma bold(X) bold(P)_sigma^top]$ on a single permuted axis:
```typst
(cal(T)(bold(X)))_(m o) = sum_(a, b = 1)^n bb(E)[(bold(P)_sigma)_(m a) (bold(P)_sigma)_(o b)] X_(a b)
= op("tr")(bold(Pi) bold(X)) bold(Pi)_(m o) + op("tr")(bold(Pi)_perp bold(X)) / (n - 1) (bold(Pi)_perp)_(m o).
```
This is the $k = 1$ prototype of both [[33d479c5|the equality-pattern basis]] and [[d47131ad|the Π/Π⊥ projector decomposition]].
