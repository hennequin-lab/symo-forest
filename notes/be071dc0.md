# Transporting invariant operators across widths

Suppose an invariant operator $bold(S)_n in cal(C)_n$ has been estimated at permuted width $n$ (in [[b50cfe81|the stable range]] $n >= 2k$) as a factor list $bold(c)_n$, and we wish to construct the corresponding invariant operator $bold(S)_(n') in cal(C)_(n')$ at another stable width $n' >= 2k$ (with the free dimensions $f_L, f_R$ unchanged).

Because $D = n^k f != (n')^k f = D'$, the ambient matrix spaces $RR^(D_L times D_R)$ and $RR^(D'_L times D'_R)$ have different dimensions. However, in [[46af9ff5|the Wedderburn decomposition]]
```typst
bold(S)_n = ⊕_lambda (bold(I)_(cal(S)_lambda (n)) ⊗ bold(B)_lambda),
```
the block matrices $bold(B)_lambda in RR^((m_lambda^L f_L) times (m_lambda^R f_R))$ live on the multiplicity-and-free spaces, whose dimensions $m_lambda^L f_L$ and $m_lambda^R f_R$ **do not depend on $n$**. The width $n$ determines only the dimension $d_lambda(n) = dim cal(S)_lambda(n)$ of the identity carrier $bold(I)_(cal(S)_lambda(n))$.

## Definition (width transport)

Let $bold(Phi)_n : bold(c)_n mapsto (bold(B)_lambda)_lambda$ denote the invertible [[f914d5ad|compile-time block dictionary]] (`Blocks.to_blocks`) at width $n$, and $bold(Phi)_(n')^(-1)$ its inverse (`Blocks.of_blocks`) at width $n'$. **Transport** from width $n$ to width $n'$ (`Blocks.transport`, lifted to parameter trees by `Orbit.Second_order.transport`) is the linear map
```typst
tau_(n -> n') = bold(Phi)_(n')^(-1) compose bold(Phi)_n.
```
In words: decode the factor list $bold(c)_n$ into its Wedderburn blocks $(bold(B)_lambda)_lambda$ using the dictionary at width $n$, and re-encode those *same* blocks $(bold(B)_lambda)_lambda$ into a factor list $bold(c)_(n') = tau_(n -> n')(bold(c)_n)$ using the inverse dictionary at width $n'$.

By definition, transport is functorial:
```typst
bold(Phi)_(n') compose tau_(n -> n') = bold(Phi)_n,
quad quad
tau_(n' -> n'') compose tau_(n -> n') = tau_(n -> n''),
quad quad
tau_(n -> n) = op("id").
```

## Proposition (invariants and scaling laws under width transport)

Let $bold(S)_n in cal(C)_n$ be a square invariant operator with Wedderburn blocks $(bold(B)_lambda)_lambda$, and let $bold(S)_(n') in cal(C)_(n')$ be the operator assembled from the transported factors $bold(c)_(n') = tau_(n -> n')(bold(c)_n)$. Then:

1. **Preservation of blocks:** The Wedderburn blocks of $bold(S)_(n')$ at width $n'$ are identically $(bold(B)_lambda)_lambda$.
2. **Preservation of distinct spectrum:** The set of distinct eigenvalues of $bold(S)_(n')$ is identical to that of $bold(S)_n$ (namely $union.big_lambda op("spec")(bold(B)_lambda)$), and $bold(S)_(n')$ is positive semidefinite (or invertible) if and only if $bold(S)_n$ is.
3. **Commutation with functional calculus:** For every analytic or spectral function $f$, transport commutes with $f$:
   ```typst
   f(bold(S)_(n')) = (tau_(n -> n') (f(bold(S)_n))),
   ```
   because both sides have the Wedderburn blocks $(f(bold(B)_lambda))_lambda$ ([[93e6cfab|block functional calculus]]).
4. **Carrier-multiplicity scaling of extensive invariants:** Because each block $bold(B)_lambda$ is repeated $d_lambda(n')$ times at width $n'$ instead of $d_lambda(n)$ times, any scalar invariant that counts eigenvalue multiplicities scales through $d_lambda(n')$:
   ```typst
   op("tr")(bold(S)_(n')) = sum_lambda d_lambda (n') op("tr")(bold(B)_lambda),
   quad quad
   op("rank")(bold(S)_(n')) = sum_lambda d_lambda (n') op("rank")(bold(B)_lambda),
   ```
   ```typst
   det(bold(S)_(n')) = product_lambda (det bold(B)_lambda)^(d_lambda (n')),
   quad quad
   |bold(S)_(n')|_F^2 = sum_lambda d_lambda (n') |bold(B)_lambda|_F^2.
   ```

### Proof

In an orthonormal basis of $W(n')$ adapted to the isotypic decomposition $W(n') ≅ ⊕_lambda cal(S)_lambda(n') ⊗ (cal(M)_lambda ⊗ F)$, $bold(S)_(n') = ⊕_lambda (bold(I)_(d_lambda(n')) ⊗ bold(B)_lambda)$ is block-diagonal with $d_lambda(n')$ identical copies of $bold(B)_lambda$ on the diagonal for each kind $lambda$. Claims (1)–(4) follow immediately from the block-diagonal representation. $square$

### Concrete trace check on the $3 times 4$ example

For a $k = 1$ leaf with $f = 4$ ([[57bf40fa|the 3×4 worked example]]), the two carrier dimensions are $d_emptyset(n) = 1$ and $d_([1])(n) = n - 1$. Transporting $bold(S)$ from $n = 3$ ($12 times 12$ matrix) to $n' = 8$ ($32 times 32$ matrix) preserves both $4 times 4$ blocks $bold(B)_emptyset$ and $bold(B)_([1])$ and all their eigenvalues, while increasing the trace from $op("tr")(bold(B)_emptyset) + 2 op("tr")(bold(B)_([1]))$ to $op("tr")(bold(B)_emptyset) + 7 op("tr")(bold(B)_([1]))$. Any diagnostic computed from the blocks $(bold(B)_lambda)_lambda$ must weight each block by $d_lambda(n)$. Why one must use $tau_(n -> n')$ rather than reusing the raw coordinate vector $bold(c)_n$ at width $n'$ is demonstrated in [[3862bdb6|the naive surrogate pitfall]].
