# Architectural equivariance versus objective invariance

Let $f(bold(w), bold(x))$ be a network parameterized by $bold(w) in W$ and let $rho : cal(G) -> O(W)$ be an orthogonal action of a group $cal(G)$ on $W$. For the orbit $cal(G) bold(w) = {rho(g) bold(w) : g in cal(G)}$ to lie inside a level set of the training objective $cal(L) : W -> RR$ — and therefore for [[6b12a533|gradient equivariance]] $nabla cal(L)(rho(g) bold(w)) = rho(g) nabla cal(L)(bold(w))$ to hold — invariance is required of the *entire objective* $cal(L)$, not merely of the bare forward map $f$.

Write a regularized empirical loss over a dataset ${(bold(x)_i, bold(y)_i)}_(i=1)^N$ as
```typst
cal(L)(bold(w)) = 1/N sum_(i=1)^N ell(f(bold(w), bold(x)_i), bold(y)_i) + R(bold(w)),
```
where $ell$ is a per-sample loss and $R : W -> RR$ is a regularizer. If $f(rho(g) bold(w), bold(x)) = f(bold(w), bold(x))$ for all $g in cal(G)$, then the data term is automatically $cal(G)$-invariant; invariance of $cal(L)$ reduces to $R(rho(g) bold(w)) = R(bold(w))$.

## Preserved vs broken invariance

1. **Isotropic $L_2$ regularization (weight decay) preserves invariance.** If $R(bold(w)) = sum_(i=1)^L frac(gamma_i, 2) |bold(w)_i|_2^2$ assigns a single scalar weight decay $gamma_i >= 0$ to each parameter leaf $W_i$, then because each leaf representation $rho_i (g)$ is [[588b9727|orthogonal]],
   ```typst
   |rho_i (g) bold(w)_i|_2^2 = bold(w)_i^top rho_i (g)^top rho_i (g) bold(w)_i = |bold(w)_i|_2^2,
   ```
   so $R(rho(g) bold(w)) = R(bold(w))$.
2. **Coordinatewise symmetric regularizers ($L_1$, $L_p$) preserve permutation invariance.** For any permutation or signed-permutation matrix $bold(A) in cal(B)_n$, the set of absolute coordinate values ${|w_(i,alpha)|}$ of a leaf is merely reordered, so $sum_alpha |w_(i,alpha)|^p$ is invariant under $cal(S)_n$ and $cal(B)_n$ (though not under continuous $O(n)$ rotations for $p != 2$).
3. **Anisotropic penalties break invariance.** Any regularizer $R(bold(w)) = frac(1, 2) bold(w)^top bold(Lambda) bold(w)$ whose precision matrix $bold(Lambda)$ does not commute with $rho(g)$ (for example, assigning distinct penalty weights $lambda_1 != lambda_2$ to different hidden units of the same layer) satisfies $R(rho(g) bold(w)) != R(bold(w))$.
4. **Unpermuted unit-indexed buffers break invariance.** If a layer depends on auxiliary unit-indexed state — such as fixed per-channel scale buffers, positional embeddings added along a permuted axis, or batch-normalization running means $bold(mu) in RR^n$ and variances $bold(sigma)^2 in RR^n$ — then permuting the weights $bold(w)$ without simultaneously permuting the auxiliary state by $bold(P)_sigma$ changes the forward map $f$. Conversely, if the auxiliary state is included in the parameter tree with symmetry specification `Symmetry.Perm id` matching the unit axis ([[dc31c6c2|symmetry declarations]]), invariance of $f$ is restored.

Note that **computing** the orbit averages $cal(R)_1(bold(v))$ and $cal(R)_2(bold(u), bold(v))$ is a purely algebraic projection on $W$ and $W ⊗ W$ ([[6226b6f2|first-order projection]], [[8eb163bd|second-order projection]]): the projection operators depend only on the declared representation $rho : cal(G) -> O(W)$, while invariance of $cal(L)$ is what identifies $rho(g) nabla cal(L)(bold(w))$ with the gradient $nabla cal(L)(rho(g) bold(w))$ at the transformed point $rho(g) bold(w)$.
