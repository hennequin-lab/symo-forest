# The Π/Π⊥ projector basis and the row mean–covariance identity

For a single permuted axis of dimension $n$ and a free space of dimension $f$ ($W = RR^n ⊗ RR^f$), [[33d479c5|the equality-pattern basis]] writes any operator $bold(S) in cal(C)(W, W)$ as
```typst
bold(S) = bold(I)_n ⊗ bold(F) + bold(J)_n ⊗ bold(G), quad bold(F), bold(G) in RR^(f times f).
```
While ${bold(I)_n, bold(J)_n}$ are sparse binary matrices well suited for einsum contractions, they are neither orthogonal ($⟨bold(I)_n, bold(J)_n⟩_F = op("tr")(bold(J)_n) = n != 0$) nor mutually annihilating ($bold(I)_n bold(J)_n = bold(J)_n != bold(0)$).

## Change of basis to orthogonal idempotents

Introduce the two orthogonal projectors on $V = RR^n$:
```typst
bold(Pi) = 1/n bold(J)_n = 1/n bold(1)_n bold(1)_n^top,
quad quad
bold(Pi)_perp = bold(I)_n - bold(Pi) = bold(I)_n - 1/n bold(J)_n.
```
They decompose $RR^n = cal(S)_emptyset ⊕ cal(S)_([1])$ into the $1$-dimensional trivial subspace $cal(S)_emptyset = op("span")(bold(1)_n) = op("im")(bold(Pi))$ and the $(n - 1)$-dimensional zero-sum standard subspace $cal(S)_([1]) = bold(1)_n^perp = op("im")(bold(Pi)_perp)$, and satisfy the orthogonal idempotent relations
```typst
bold(Pi)^2 = bold(Pi), quad bold(Pi)_perp^2 = bold(Pi)_perp, quad bold(Pi) bold(Pi)_perp = bold(Pi)_perp bold(Pi) = bold(0), quad bold(Pi) + bold(Pi)_perp = bold(I)_n.
```
Substituting $bold(I)_n = bold(Pi) + bold(Pi)_perp$ and $bold(J)_n = n bold(Pi)$ into $bold(S) = bold(I)_n ⊗ bold(F) + bold(J)_n ⊗ bold(G)$ gives the **Wedderburn projector form**:
```typst
bold(S) = bold(Pi) ⊗ bold(B)_emptyset + bold(Pi)_perp ⊗ bold(B)_([1]),
```
where the two $f times f$ **block matrices** $bold(B)_emptyset, bold(B)_([1]) in RR^(f times f)$ (also denoted $bold(F)_parallel$ and $bold(F)_perp$) are related to $(bold(F), bold(G))$ by the invertible linear transformation
```typst
bold(B)_([1]) = bold(F), quad quad
bold(B)_emptyset = bold(F) + n bold(G)
quad <==> quad
bold(F) = bold(B)_([1]), quad
bold(G) = 1/n (bold(B)_emptyset - bold(B)_([1])).
```
Because $bold(Pi)$ and $bold(Pi)_perp$ are orthogonal projectors onto complementary subspaces of dimensions $d_emptyset = 1$ and $d_([1]) = n - 1$, there exists an orthogonal matrix $bold(Q) in O(n)$ (whose first column is $bold(1)_n / sqrt(n)$ and whose remaining $n - 1$ columns span $bold(1)_n^perp$) such that $bold(Q)^top bold(Pi) bold(Q) = op("Diag")(1, 0, dots, 0)$ and $bold(Q)^top bold(Pi)_perp bold(Q) = op("Diag")(0, 1, dots, 1)$. In the adapted basis $bold(Q) ⊗ bold(I)_f$, $bold(S)$ is explicitly block-diagonal:
```typst
(bold(Q) ⊗ bold(I)_f)^top bold(S) (bold(Q) ⊗ bold(I)_f) = op("Diag") lr((bold(B)_emptyset, underbrace(bold(B)_([1]) comma dots comma bold(B)_([1]), n - 1 "copies"))).
```

## Proposition (the row mean–covariance identity)

Let $bold(C) in RR^(n times f)$ be a matrix with rows $bold(c)_1^top, dots, bold(c)_n^top in RR^f$ and vectorization $bold(c) = op("vec")(bold(C)) in RR^(n f)$ (ordered row by row, so $bold(c)_((m, alpha)) = C_(m alpha)$). Define the sample mean row $overline(bold(c)) in RR^f$ and the unbiased sample row covariance $op("Cov")(bold(C)) in RR^(f times f)$ by
```typst
overline(bold(c)) = 1/n sum_(m=1)^n bold(c)_m,
quad quad
op("Cov")(bold(C)) = 1/(n - 1) sum_(m=1)^n (bold(c)_m - overline(bold(c))) (bold(c)_m - overline(bold(c)))^top.
```
Then the second-order orbit average $bold(S) = cal(R)_2(bold(c), bold(c))$ under row permutations $cal(S)_n$ has the exact Wedderburn blocks
```typst
bold(B)_emptyset = n overline(bold(c)) overline(bold(c))^top,
quad quad
bold(B)_([1]) = op("Cov")(bold(C)),
```
so that
```typst
cal(R)_2 (bold(c), bold(c)) = bold(Pi) ⊗ (n overline(bold(c)) overline(bold(c))^top) + bold(Pi)_perp ⊗ op("Cov")(bold(C)).
```

### Proof

By [[273c28e5|the second-moment identity for random permutations]],
```typst
bb(E)_(sigma in cal(S)_n) [ (bold(P)_sigma)_(m a) (bold(P)_sigma)_(o b) ]
= bold(Pi)_(m o) bold(Pi)_(a b) + 1/(n - 1) (bold(Pi)_perp)_(m o) (bold(Pi)_perp)_(a b).
```
Applying this expectation to the $(m, alpha), (o, beta)$ entry of $cal(R)_2(bold(c), bold(c)) = bb(E)_sigma[(bold(P)_sigma ⊗ bold(I)_f) bold(c) bold(c)^top (bold(P)_sigma^top ⊗ bold(I)_f)]$ yields
```typst
(cal(R)_2 (bold(c), bold(c)))_((m, alpha), (o, beta))
= sum_(a, b = 1)^n bb(E)[(bold(P)_sigma)_(m a) (bold(P)_sigma)_(o b)] C_(a alpha) C_(b beta)
= bold(Pi)_(m o) lr((bold(C)^top bold(Pi) bold(C)))_(alpha beta) + (bold(Pi)_perp)_(m o) lr((1/(n - 1) bold(C)^top bold(Pi)_perp bold(C)))_(alpha beta).
```
Now evaluate the two $f times f$ matrices on the right:
1. Since $bold(Pi) = frac(1, n) bold(1)_n bold(1)_n^top$ and $bold(C)^top bold(1)_n = n overline(bold(c))$,
   ```typst
   bold(C)^top bold(Pi) bold(C) = 1/n (bold(C)^top bold(1)_n)(bold(C)^top bold(1)_n)^top = n overline(bold(c)) overline(bold(c))^top = bold(B)_emptyset.
   ```
2. Since $bold(Pi)_perp = bold(Pi)_perp^2$ and $(bold(Pi)_perp bold(C))_(m, :) = bold(c)_m^top - overline(bold(c))^top$,
   ```typst
   1/(n - 1) bold(C)^top bold(Pi)_perp bold(C) = 1/(n - 1) (bold(Pi)_perp bold(C))^top (bold(Pi)_perp bold(C)) = 1/(n - 1) sum_(m=1)^n (bold(c)_m - overline(bold(c)))(bold(c)_m - overline(bold(c)))^top = op("Cov")(bold(C)) = bold(B)_([1]).
   ```
This establishes the decomposition. $square$

Notice the distinct roles of $n$ in the two blocks: for a distribution of rows with fixed mean $overline(bold(c))$ and covariance $op("Cov")(bold(C))$, $bold(B)_([1])$ is independent of $n$ while $bold(B)_emptyset = n overline(bold(c)) overline(bold(c))^top$ scales with $n$. This distinction between raw pattern coefficients and Wedderburn blocks is the subject of [[790ac25a|factor coordinates versus Wedderburn blocks]].
