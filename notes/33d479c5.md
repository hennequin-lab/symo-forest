# Index invariance and the equality-pattern basis

Consider a parameter leaf $W = V ⊗ F$ with one permuted axis $V = RR^n$ ($k = 1$) and a free space $F = RR^f$, so that $dim W = D = n f$ and the symmetric group $cal(S)_n$ acts by $rho(sigma) = bold(P)_sigma ⊗ bold(I)_f$. Index the rows of an operator $bold(S) in RR^(n f times n f)$ by the pair $(m, alpha)$ and its columns by $(o, beta)$, where $m, o in {1, dots, n}$ are the permuted unit indices and $alpha, beta in {1, dots, f}$ are the free indices.

By definition of [[8eb163bd|the commutant]] $cal(C)(W, W)$, $bold(S)$ commutes with $rho(sigma) = bold(P)_sigma ⊗ bold(I)_f$ for all $sigma in cal(S)_n$ if and only if
```typst
bold(S) = (bold(P)_sigma ⊗ bold(I)_f) bold(S) (bold(P)_sigma^top ⊗ bold(I)_f)
<==>
bold(S)_((m, alpha), (o, beta)) = bold(S)_((sigma(m), alpha), (sigma(o), beta)) quad forall sigma in cal(S)_n.
```

## Transitivity of $cal(S)_n$ on index pairs

For $n >= 2$, the action of $cal(S)_n$ on ordered pairs $(m, o) in {1, dots, n}^2$ partitions ${1, dots, n}^2$ into exactly two orbits:
1. **The diagonal orbit** ${(m, m) : 1 <= m <= n}$ of size $n$ (since $sigma(m) = sigma(o) <==> m = o$).
2. **The off-diagonal orbit** ${(m, o) : m != o}$ of size $n(n - 1)$ (since for any two distinct pairs $(m, o)$ with $m != o$ and $(m', o')$ with $m' != o'$, there exists a permutation $sigma in cal(S)_n$ sending $m mapsto m'$ and $o mapsto o'$).

Because $bold(S)_((m, alpha), (o, beta))$ must be constant along each $cal(S)_n$-orbit for every fixed free-index pair $(alpha, beta)$, $bold(S)$ has at most two distinct values per $(alpha, beta)$: one value $A_(alpha beta)$ when $m = o$, and one value $B_(alpha beta)$ when $m != o$. Writing $delta_(m o)$ for the Kronecker delta and $1_(m o) = 1$ for the all-ones tensor on the permuted indices,
```typst
bold(S)_((m, alpha), (o, beta))
= delta_(m o) A_(alpha beta) + (1 - delta_(m o)) B_(alpha beta)
= delta_(m o) bold(F)_(alpha beta) + 1_(m o) bold(G)_(alpha beta),
```
where $bold(F) = bold(A) - bold(B) in RR^(f times f)$ and $bold(G) = bold(B) in RR^(f times f)$. In Kronecker product notation,
```typst
bold(S) = bold(I)_n ⊗ bold(F) + bold(J)_n ⊗ bold(G).
```

## Dimension reduction

This expansion is an *exact characterization* of $cal(C)(V ⊗ F, V ⊗ F)$, not an approximation:
- A general matrix in $RR^(n f times n f)$ has $D^2 = n^2 f^2$ entries (or $frac(n f(n f + 1), 2)$ if symmetric).
- An operator in $cal(C)(V ⊗ F, V ⊗ F)$ is completely specified by the two $f times f$ matrices $bold(F)$ and $bold(G)$, requiring
  ```typst
  dim cal(C)(V ⊗ F, V ⊗ F) = 2 f^2
  ```
  numbers (or $2 dot frac(f(f + 1), 2) = f(f + 1)$ independent numbers when $bold(S) = bold(S)^top$, which forces $bold(F) = bold(F)^top$ and $bold(G) = bold(G)^top$). The dimension of the commutant is completely independent of the permuted width $n$.

For a concrete numerical illustration with $n = 3, f = 4$, see [[57bf40fa|the 3×4 worked example]]. For the reformulation in terms of orthogonal projectors $bold(Pi), bold(Pi)_perp$, see [[d47131ad|the Π/Π⊥ projector basis]]. For the generalization to $k_L + k_R$ permuted axes via set partitions, see [[a0bb3d95|partial partitions and Bell numbers]].
