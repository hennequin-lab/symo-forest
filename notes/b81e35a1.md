# Symbolic Gram matrix via the partition lattice

The diagram basis tensors ${bold(T)_P}$ defined in [[a0bb3d95|partial partitions and diagram terms]] span the commutant $cal(C)(V^(⊗k_R), V^(⊗k_L))$, but they are **not mutually orthogonal** under the Frobenius inner product $⟨bold(A), bold(B)⟩_F = sum_(bold(i), bold(j)) A_(bold(i), bold(j)) B_(bold(i), bold(j))$. For instance, when $k_L = k_R = 1$, the two partial partitions are $P_1 = {{L_0, R_0}}$ (the identity $bold(T)_(P_1) = bold(I)_n$, with $alpha_(P_1) = 1$) and $P_2 = emptyset$ (the scaled all-ones matrix $bold(T)_(P_2) = frac(1, n) bold(J)_n$, with two untied axes so $alpha_(P_2) = (n^2)^(-1/2) = frac(1, n)$). Their Frobenius inner product is
```typst
⟨bold(T)_(P_1), bold(T)_(P_2)⟩_F = 1/n op("tr")(bold(I)_n bold(J)_n) = 1/n dot n = 1 != 0.
```

Because ${bold(T)_P}$ is non-orthogonal, computing the coordinates of an orthogonal projection onto $cal(C)$ requires the **Gram matrix** (called the `design_matrix` in `Component.design_matrix`)
```typst
bold(G)_(P Q) = ⟨bold(T)_P, bold(T)_Q⟩_F.
```
Naively evaluating $bold(G)_(P Q)$ by forming $bold(T)_P$ and $bold(T)_Q$ and summing over all $n^(k_L + k_R)$ index tuples would cost $O(n^(k_L + k_R))$ operations and would be impossible at large $n$. Instead, `Term.inner_product` computes $bold(G)_(P Q)$ **symbolically in $O(1)$ time** from the partition lattice.

## Proposition (symbolic inner product via the partition join)

Let $P$ and $Q$ be two partial partitions of the permuted index set $cal(I)$ (with $|cal(I)| = k_L + k_R$), corresponding to full set partitions $pi(P)$ and $pi(Q)$ of $cal(I)$ once singleton blocks are restored. Let $pi(P) or pi(Q)$ denote their **join** (finest common coarsening) in the lattice of set partitions of $cal(I)$ — that is, the equivalence classes of the transitive closure of the union of all equality constraints in $P$ and $Q$. Then
```typst
⟨bold(T)_P, bold(T)_Q⟩_F = alpha_P alpha_Q product_(C in pi(P) or pi(Q)) dim(C),
```
where $dim(C) = n$ is the dimension of the group whose axes lie in the connected component $C$. When all $k = k_L + k_R$ axes belong to a single group of dimension $n$,
```typst
⟨bold(T)_P, bold(T)_Q⟩_F = alpha_P alpha_Q n^(|pi(P) or pi(Q)|),
```
where $|pi(P) or pi(Q)|$ is the number of blocks (including singletons) in the joined set partition.

### Proof

By definition of $bold(T)_P$ and $bold(T)_Q$,
```typst
⟨bold(T)_P, bold(T)_Q⟩_F
= alpha_P alpha_Q sum_((i_x)_(x in cal(I)) in {1, dots, n}^k) lr((product_(B in P) delta_B (bold(i)))) lr((product_(B' in Q) delta_(B') (bold(i)))).
```
For a given index tuple $bold(i) = (i_x)_(x in cal(I))$, the product of Kronecker deltas $lr((product_(B in P) delta_B(bold(i))))lr((product_(B' in Q) delta_(B')(bold(i))))$ equals $1$ if and only if $i_x = i_y$ for every pair $(x, y)$ belonging to a block of $P$ *and* for every pair $(x, y)$ belonging to a block of $Q$; otherwise it is $0$. By transitivity of equality, this holds if and only if $bold(i)$ is constant on each equivalence class $C in pi(P) or pi(Q)$.

Each equivalence class $C in pi(P) or pi(Q)$ can be assigned any value in ${1, dots, dim(C)}$ independently, while every axis $x$ that appears in neither $P$ nor $Q$ forms a singleton equivalence class ${x} in pi(P) or pi(Q)$ contributing a factor of $dim(x)$ ("`contrib_from_ones`" in `Term.inner_product`). Multiplying the number of choices across all equivalence classes $C in pi(P) or pi(Q)$ yields $product_(C in pi(P) or pi(Q)) dim(C)$. $square$

## Worked check on $k_L = k_R = 1$

For $P_1 = {{L_0, R_0}}$ ($alpha_(P_1) = 1$, $|pi(P_1)| = 1$) and $P_2 = emptyset$ ($alpha_(P_2) = n^(-1)$, $|pi(P_2)| = 2$):
- $G_(1 1) = 1 dot 1 dot n^(|pi(P_1) or pi(P_1)|) = n^1 = n$.
- $G_(1 2) = 1 dot n^(-1) dot n^(|pi(P_1) or pi(P_2)|) = n^(-1) dot n^1 = 1$.
- $G_(2 2) = n^(-1) dot n^(-1) dot n^(|pi(P_2) or pi(P_2)|) = n^(-2) dot n^2 = 1$.

Thus the $2 times 2$ Gram matrix on the permuted factor is
```typst
bold(G) = mat(n, 1; 1, 1), quad quad
det(bold(G)) = n - 1 > 0 quad "for all" n >= 2.
```
Notice directly from $det(bold(G)) = n - 1$ why the basis becomes degenerate at $n = 1$ (outside the stable range $n >= 2k = 2$; see [[b50cfe81|the stable range]]). How $bold(G)$ is used to compute the exact projection coordinates of $bold(u) bold(v)^top$ is detailed in [[e176661b|the compile-time projection solve]].
