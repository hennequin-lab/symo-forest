Declarative symmetry specifications on parameter trees

#implementation

In symo, symmetries are declared explicitly per axis of each parameter tensor rather than inferred heuristically. A model is a module satisfying Symo.Orbit.Model: it defines a polymorphic record or variant type with [@@deriving ptree], a dims tree giving the shape int list of each leaf, and a symmetries tree assigning one Symmetry.spec to each axis of each leaf.

The axis specification grammar (Symmetry.spec)

type spec =
  | Absent    (* pads a side of a commutation equation with no axis, e.g. R1 *)
  | Id        (* free axis: untouched by every symmetry group *)
  | Perm of int (* permuted axis tied to group id i *)

The scoping rules across the parameter tree are enforced by Orbit.Make:

  1. Shared group IDs couple axes across leaves. Every axis tagged Perm i anywhere in the parameter tree is transformed simultaneously by the same permutation . Accordingly, Orbit.Make verifies at functor instantiation that all axes tagged Perm i across all leaves have the identical dimension , and Kind.check_stable verifies that on every leaf (the stable range).
  2. Repeated group IDs within one leaf define higher-order tensor powers. If Perm i appears times in the specification list of a single leaf (for example, [Perm 0; Perm 0] on a square recurrent matrix), that leaf transforms under the -th tensor power (two-sided conjugation).
  3. Distinct group IDs commute. Axes tagged Perm i and Perm j with belong to independent factors of the direct-product group (crossing groups).

Complete example: instantiating Orbit.Make on a two-layer MLP

open Symo

module Mlp = struct
  type ('a, _) t =
    { w1 : 'a   (* hidden x input:  32 x 8 *)
    ; b1 : 'a   (* hidden:          32     *)
    ; w2 : 'a   (* output x hidden:  4 x 32 *)
    }
  [@@deriving ptree]

  let dims : (int list, _) t =
    { w1 = [ 32; 8 ]; b1 = [ 32 ]; w2 = [ 4; 32 ] }

  (* Group 0 (S_32) permutes the 32 hidden units across w1, b1, and w2.
     The 8 inputs of w1 and 4 outputs of w2 are free (Id). *)
  let symmetries : (Symmetry.spec list, _) t =
    { w1 = [ Symmetry.Perm 0; Symmetry.Id ]
    ; b1 = [ Symmetry.Perm 0 ]
    ; w2 = [ Symmetry.Id; Symmetry.Perm 0 ]
    }
end

module O = Orbit.Make (Mlp)

Instantiating Orbit.Make (Mlp) compiles all basis terms, Gram Cholesky factors, and block conversion tables once and exposes:

  • O.random_transform ~key theta: draws one uniformly random permutation per group ID (Perm 0 ) and applies across all leaves of theta.
  • O.First_order.orbit_average theta: computes the exact first-order projection (compiled as a commutation equation with right = [Symmetry.Absent]).
  • O.Second_order.factors_of_pair u v: computes the factor coordinates of the second-order orbit average across all leaf pairs in time (compile-time projection solve).
  • O.Second_order.apply ~factors v: evaluates the matrix–vector product directly from the factor list without materializing the matrix (einsum compilation).
  • O.Second_order.blocks_of_factors and O.Second_order.factors_of_blocks: maps between factor lists and the assembled Wedderburn block matrices via the compile-time dictionary.
  • O.Second_order.transport ~dims factors: re-encodes an operator's factor list at a new permuted width while preserving its Wedderburn blocks (width transport).
