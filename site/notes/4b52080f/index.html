A GRU multiplies the mosaic

#recurrence

A GRU has three square matrices (one per gate), plus input maps, all permuted by the same on both sides. Each gate contributes its own fifteen-pattern block (the fifteen numbers), the readout and input maps contribute their two-pattern strips, and the whole mosaic stays inside the same algebra — bigger, but with tiles of the same combinatorial size.

This is the case the author would most like to see trained at scale. The curvature of a gated recurrent network is, in this framework, a small number of fifteen-dimensional objects per layer, plus strips. The width of the state does not change the number of objects; it only changes the size of the carriers on which the operator is the identity.

The structure follows from the whole-computation symmetry: every tensor that touches the state is tied by the same group, and each gate is another tensor with the same two-sided action as the vanilla recurrence (the vanilla case). The cross tiles between gates are the analogue of cross tiles in the MLP-step RNN.

Whether the gated case trains as well as the vanilla one is an empirical question, and the framework's evidence is mostly on feedforward nets and a small RNN smoke test (does it train).
