Two equality questions make four values per tile

Inside the tile of the RNN mosaic, the entry can depend only on two yes/no questions:

The two groups act independently, so the two questions are independent. Two yes/no questions give four patterns, and four values. The tile of has exactly four distinct entries, and so does 's.

The count is combinatorial, not architectural. It does not depend on the number of hidden or state units, only on the number of groups acting on the tensor's two axes. A bigger network has a bigger tile with the same four numbers in it.
