Multi-leaf parameter trees and recurrent mosaics — trailhead

#meta#recurrence

In a feedforward network where each hidden layer has its own independent permutation group, a group id is shared only between the outgoing axis of layer and the incoming axis of layer . In a recurrent architecture, by contrast, the recurrent state vector is updated and read out at every time step. A permutation () therefore acts simultaneously on every parameter tensor that touches the state — across both sides of square transition matrices, input projections, biases, and readouts.

When the second-order orbit average is formed over the entire parameter tree , it partitions into an grid of blocks — a mosaic of diagonal and cross-leaf intertwiners.
