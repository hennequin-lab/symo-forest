This is the first concrete instance of the general principle: the group cannot see which unit is which, so the only thing an average can retain is the aggregate over units. The second-order version replaces "mean row" with "which indices are equal"; it is the second-order average.

The formula is also a check on any implementation: for a random permutation matrix, mean(P) should be ones/n to machine precision. The library's first-order average should reproduce the row mean exactly (module layout).
